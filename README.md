# CSCrosshairScale

A Minecraft mod (Fabric) that allows you to change the size of the vanilla crosshair without altering its texture or shape.

## Features
- Configurable crosshair scale (0.25x to 4.0x)
- In-game settings screen with live preview
- Mod Menu support
- Keybindings to open settings and adjust scale on the fly

## Requirements
- Minecraft 1.21.11
- Fabric Loader (>=0.19.5)
- Fabric API

## Build
```bash
./gradlew build
```
